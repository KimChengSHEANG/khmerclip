**KhmerClipper** reads Khmer (and English) text from anywhere on your screen and copies it, ready to paste.

## What's new

- **New name: KhmerClipper** (was KhmerClip), with a new icon.
- **TrOCR is now the default engine.** It is far more accurate on Khmer than Tesseract. On Windows and Linux its model (about 1.5 GB) starts downloading in the background the first time the app opens. Until it finishes, switch to Tesseract in **Preferences → OCR Engine** if you need to capture right away.
- **History shows a picture of each capture** next to its text.
- **The capture box on Windows and Linux now matches the Mac one**: the screen stays bright, and a label shows the box size as you drag.

## Upgrading from KhmerClip 0.2.0

KhmerClipper installs as a new app, so it won't replace KhmerClip. Uninstall KhmerClip first, so the two apps don't fight over the same shortcut:

- **Mac:** quit KhmerClip and move it from Applications to the Trash.
- **Windows:** Settings → Apps → KhmerClip → Uninstall.
- **Ubuntu / Debian:** `sudo apt remove khmerclip`

Your preferences and history from KhmerClip don't carry over.

## Download

Pick the file for your computer, under **Assets** below.

| Computer | File |
|---|---|
| Mac (macOS 15 or newer) | `KhmerClipper-0.2.1.dmg` |
| Windows 10 / 11 (64-bit) | `KhmerClipper-0.2.1-windows-x64-setup.exe` |
| Ubuntu / Debian (64-bit) | `khmerclipper_0.2.1_amd64.deb` |
| Other Linux (64-bit) | `KhmerClipper-0.2.1-x86_64.AppImage` |

## Install

### Mac

1. Open `KhmerClipper-0.2.1.dmg` and drag **KhmerClipper** onto **Applications**.
2. Open KhmerClipper from Applications. Its icon appears in the menu bar at the top of the screen.
3. When asked, allow **Screen Recording** (System Settings → Privacy & Security → Screen Recording), then reopen KhmerClipper.

### Windows

1. Double-click `KhmerClipper-0.2.1-windows-x64-setup.exe`.
2. If you see **"Windows protected your PC"**, click **More info**, then **Run anyway**. This appears because the app isn't signed with a paid Microsoft certificate yet. It is safe to install.
3. Follow the steps to finish installing. KhmerClipper starts in the system tray (bottom-right corner of the screen).

### Ubuntu / Debian

1. Download `khmerclipper_0.2.1_amd64.deb`, then run `sudo apt install ./khmerclipper_0.2.1_amd64.deb` in a terminal in the download folder.
2. Open **KhmerClipper** from the app menu. Its icon appears in the top bar.

### Other Linux

AppImages need FUSE 2. On Ubuntu 22.04 run `sudo apt install libfuse2`; on 24.04 and newer, `sudo apt install libfuse2t64`.

1. Make the file executable: right-click → Properties → Permissions → **Allow executing file as program**, or run `chmod +x KhmerClipper-0.2.1-x86_64.AppImage`.
2. Double-click it to start. On GNOME, the tray icon needs the **AppIndicator** extension (already on in Ubuntu).

## Use

1. Press **⌘⇧6** (Mac) or **Ctrl+Shift+2** (Windows / Linux), or choose **Capture Text** from the KhmerClipper icon.
2. Drag a box around the text. The text is copied. Paste it anywhere.

**Wayland (Linux):** add a keyboard shortcut in your desktop settings that runs `khmerclipper --capture` (.deb) or `/path/to/KhmerClipper-0.2.1-x86_64.AppImage --capture`.

---

Everything runs on your computer. Your screen captures are never uploaded.
