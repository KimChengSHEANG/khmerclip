**KhmerClip** reads Khmer (and English) text from anywhere on your screen and copies it, ready to paste.

## What's new

- **Much better at reading paragraphs from the screen.** Khmer lines that touch each other are now separated, long lines are read in pieces, and each line is trimmed to its text. On our test set of screen captures, errors dropped by about 85%.
- **New TrOCR model (v3)**, trained on small screen-style text. Fewer errors on bold, display and mixed Khmer/English text too.
- **Ubuntu package (.deb)**: install it like any other app.

## Download

Pick the file for your computer, under **Assets** below.

| Computer | File |
|---|---|
| Mac (macOS 15 or newer) | `KhmerClip-0.2.0.dmg` |
| Windows 10 / 11 (64-bit) | `KhmerClip-0.2.0-windows-x64-setup.exe` |
| Ubuntu / Debian (64-bit) | `khmerclip_0.2.0_amd64.deb` |
| Other Linux (64-bit) | `KhmerClip-0.2.0-x86_64.AppImage` |

## Install

### Mac

1. Open `KhmerClip-0.2.0.dmg` and drag **KhmerClip** onto **Applications**.
2. Open KhmerClip from Applications. Its icon appears in the menu bar at the top of the screen.
3. If macOS says it can't check the app for malicious software, open **System Settings → Privacy & Security** and click **Open Anyway**. This appears because the app isn't notarized by Apple yet.
4. When asked, allow **Screen Recording** (System Settings → Privacy & Security → Screen Recording), then reopen KhmerClip.

### Windows

1. Double-click `KhmerClip-0.2.0-windows-x64-setup.exe`.
2. If you see **"Windows protected your PC"**, click **More info**, then **Run anyway**. This appears because the app isn't signed with a paid Microsoft certificate yet. It is safe to install.
3. Follow the steps to finish installing. KhmerClip starts in the system tray (bottom-right corner of the screen).

### Ubuntu / Debian

1. Download `khmerclip_0.2.0_amd64.deb`, then run `sudo apt install ./khmerclip_0.2.0_amd64.deb` in a terminal in the download folder.
2. Open **KhmerClip** from the app menu. Its icon appears in the top bar.

### Other Linux

AppImages need FUSE 2. On Ubuntu 22.04 run `sudo apt install libfuse2`; on 24.04 and newer, `sudo apt install libfuse2t64`.

1. Make the file executable: right-click → Properties → Permissions → **Allow executing file as program**, or run `chmod +x KhmerClip-0.2.0-x86_64.AppImage`.
2. Double-click it to start. On GNOME, the tray icon needs the **AppIndicator** extension (already on in Ubuntu).

## Use

1. Press **⌘⇧6** (Mac) or **Ctrl+Shift+2** (Windows / Linux), or choose **Capture Text** from the KhmerClip icon.
2. Drag a box around the text. The text is copied. Paste it anywhere.

**Better Khmer accuracy:** in **Preferences → OCR Engine**, choose **TrOCR**. On Windows and Linux it downloads once (about 1.5 GB) the first time you use it.

**Wayland (Linux):** add a keyboard shortcut in your desktop settings that runs `khmerclip --capture` (.deb) or `/path/to/KhmerClip-0.2.0-x86_64.AppImage --capture`.

---

Everything runs on your computer. Your screen captures are never uploaded.
