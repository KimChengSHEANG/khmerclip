**KhmerClip** reads Khmer (and English) text from anywhere on your screen and copies it, ready to paste.

**KhmerClip** អានអក្សរខ្មែរ (និងអង់គ្លេស) ពីកន្លែងណាក៏បានលើអេក្រង់របស់អ្នក ហើយចម្លងទុក ដើម្បីយកទៅបិទភ្ជាប់ (paste) បានភ្លាមៗ។

## What's new · អ្វីថ្មី

- **Much better at reading paragraphs from the screen.** Khmer lines that touch each other are now separated, long lines are read in pieces, and each line is trimmed to its text. On our test set of screen captures, errors dropped by about 85%.
- **New TrOCR model (v3)**, trained on small screen-style text. Fewer errors on bold, display and mixed Khmer/English text too.
- **Ubuntu package (.deb)**: install it like any other app.

- **អានអត្ថបទច្រើនបន្ទាត់ពីអេក្រង់បានល្អជាងមុនច្រើន។** បន្ទាត់ខ្មែរដែលជាប់គ្នាត្រូវបានបំបែកចេញពីគ្នា បន្ទាត់វែងត្រូវបានអានជាផ្នែកៗ ហើយបន្ទាត់នីមួយៗត្រូវបានកាត់ឱ្យសល់តែអក្សរ។ លើសំណុំតេស្តរូបភាពអេក្រង់របស់យើង កំហុសថយចុះប្រហែល ៨៥%។
- **ម៉ូដែល TrOCR ថ្មី (v3)** ដែលបានហ្វឹកហាត់លើអក្សរតូចៗដូចនៅលើអេក្រង់។ កំហុសតិចជាងមុនលើអក្សរដិត អក្សរតុបតែង និងអក្សរខ្មែរលាយអង់គ្លេស។
- **កញ្ចប់សម្រាប់ Ubuntu (.deb)**៖ ដំឡើងដូចកម្មវិធីផ្សេងទៀតដែរ។

## Install · ការដំឡើង

### Mac

1. Open `KhmerClip-0.2.0.dmg` and drag **KhmerClip** onto **Applications**.
2. Open KhmerClip from Applications. Its icon appears in the menu bar at the top of the screen.
3. If macOS says it can't check the app for malicious software, open **System Settings → Privacy & Security** and click **Open Anyway**. This appears because the app isn't notarized by Apple yet.
4. When asked, allow **Screen Recording** (System Settings → Privacy & Security → Screen Recording), then reopen KhmerClip.

1. បើក `KhmerClip-0.2.0.dmg` ហើយអូស **KhmerClip** ទៅដាក់ក្នុង **Applications**។
2. បើក KhmerClip ពី Applications។ រូបតំណាងរបស់វានឹងបង្ហាញនៅលើរបារម៉ឺនុយ ខាងលើអេក្រង់។
3. បើ macOS និយាយថាវាមិនអាចពិនិត្យកម្មវិធីនេះបាន សូមបើក **System Settings → Privacy & Security** ហើយចុច **Open Anyway**។ សារនេះលេចឡើងព្រោះកម្មវិធីមិនទាន់ត្រូវបាន Apple ពិនិត្យ (notarize) នៅឡើយ។
4. ពេលវាសួរ សូមអនុញ្ញាត **Screen Recording** (System Settings → Privacy & Security → Screen Recording) រួចបើក KhmerClip ម្តងទៀត។

### Windows

1. Double-click `KhmerClip-0.2.0-windows-x64-setup.exe`.
2. If you see **"Windows protected your PC"**, click **More info**, then **Run anyway**. This appears because the app isn't signed with a paid Microsoft certificate yet. It is safe to install.
3. Follow the steps to finish installing. KhmerClip starts in the system tray (bottom-right corner of the screen).

1. ចុចពីរដងលើ `KhmerClip-0.2.0-windows-x64-setup.exe`។
2. ប្រសិនបើឃើញ **"Windows protected your PC"** សូមចុច **More info** រួចចុច **Run anyway**។ សារនេះលេចឡើង ព្រោះកម្មវិធីមិនទាន់មានវិញ្ញាបនបត្រ (certificate) ពី Microsoft នៅឡើយ។ កម្មវិធីនេះមានសុវត្ថិភាពក្នុងការដំឡើង។
3. ធ្វើតាមជំហាន ដើម្បីបញ្ចប់ការដំឡើង។ KhmerClip នឹងដំណើរការនៅក្នុង system tray (ជ្រុងខាងស្តាំផ្នែកខាងក្រោមនៃអេក្រង់)។

### Ubuntu / Debian

1. Download `khmerclip_0.2.0_amd64.deb`, then run `sudo apt install ./khmerclip_0.2.0_amd64.deb` in a terminal in the download folder.
2. Open **KhmerClip** from the app menu. Its icon appears in the top bar.

1. ទាញយក `khmerclip_0.2.0_amd64.deb` រួចវាយ `sudo apt install ./khmerclip_0.2.0_amd64.deb` ក្នុង terminal នៅថតដែលបានទាញយក។
2. បើក **KhmerClip** ពីម៉ឺនុយកម្មវិធី។ រូបតំណាងរបស់វានឹងបង្ហាញនៅលើរបារខាងលើ។

### Other Linux · Linux ផ្សេងទៀត

AppImages need FUSE 2. On Ubuntu 22.04 run `sudo apt install libfuse2`; on 24.04 and newer, `sudo apt install libfuse2t64`.

AppImage ត្រូវការ FUSE 2។ នៅលើ Ubuntu 22.04 សូមវាយ `sudo apt install libfuse2` ហើយនៅលើ 24.04 ឬថ្មីជាងនេះ `sudo apt install libfuse2t64`។

1. Make the file executable: right-click → Properties → Permissions → **Allow executing file as program**, or run `chmod +x KhmerClip-0.2.0-x86_64.AppImage`.
2. Double-click it to start. On GNOME, the tray icon needs the **AppIndicator** extension (already on in Ubuntu).

1. អនុញ្ញាតឱ្យឯកសារដំណើរការបាន៖ ចុចកណ្តុរស្តាំ → Properties → Permissions → **Allow executing file as program** ឬវាយ `chmod +x KhmerClip-0.2.0-x86_64.AppImage`។
2. ចុចពីរដងលើវា ដើម្បីចាប់ផ្តើម។ នៅលើ GNOME រូបតំណាងក្នុង tray ត្រូវការ extension **AppIndicator** (Ubuntu មានរួចហើយ)។

## Use · របៀបប្រើ

1. Press **⌘⇧6** (Mac) or **Ctrl+Shift+2** (Windows / Linux), or choose **Capture Text** from the KhmerClip icon.
2. Drag a box around the text. The text is copied. Paste it anywhere.

1. ចុច **⌘⇧6** (Mac) ឬ **Ctrl+Shift+2** (Windows / Linux) ឬជ្រើស **Capture Text** ពីរូបតំណាង KhmerClip។
2. អូសប្រអប់ជុំវិញអក្សរ។ អក្សរនឹងត្រូវបានចម្លង។ យកទៅបិទភ្ជាប់ (paste) កន្លែងណាក៏បាន។

**Better Khmer accuracy · ភាពត្រឹមត្រូវខ្ពស់ជាងសម្រាប់អក្សរខ្មែរ:** in **Preferences → OCR Engine**, choose **TrOCR**. On Windows and Linux it downloads once (about 1.5 GB) the first time you use it.

នៅក្នុង **Preferences → OCR Engine** សូមជ្រើស **TrOCR**។ នៅលើ Windows និង Linux វានឹងទាញយកម្តង (ប្រហែល 1.5 GB) នៅពេលប្រើលើកដំបូង។

**Wayland (Linux):** add a keyboard shortcut in your desktop settings that runs `khmerclip --capture` (.deb) or `/path/to/KhmerClip-0.2.0-x86_64.AppImage --capture`.
