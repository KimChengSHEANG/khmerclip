**KhmerClip** reads Khmer (and English) text from anywhere on your screen and copies it, ready to paste.

**KhmerClip** អានអក្សរខ្មែរ (និងអង់គ្លេស) ពីកន្លែងណាក៏បានលើអេក្រង់របស់អ្នក ហើយចម្លងទុក ដើម្បីយកទៅបិទភ្ជាប់ (paste) បានភ្លាមៗ។

## Download · ទាញយក

Pick the file for your computer, under **Assets** below. · ជ្រើសរើសឯកសារសម្រាប់កុំព្យូទ័ររបស់អ្នក នៅក្នុង **Assets** ខាងក្រោម។

| Computer · កុំព្យូទ័រ | File · ឯកសារ |
|---|---|
| Mac (macOS 15 or newer · ឬថ្មីជាងនេះ) | `KhmerClip-0.1.0.dmg` |
| Windows 10 / 11 (64-bit) | `KhmerClip-0.1.0-windows-x64-setup.exe` |
| Linux (64-bit) | `KhmerClip-0.1.0-x86_64.AppImage` |

## Install · ការដំឡើង

### Mac

1. Open `KhmerClip-0.1.0.dmg` and drag **KhmerClip** onto **Applications**.
2. Open KhmerClip from Applications. Its icon appears in the menu bar at the top of the screen.
3. When asked, allow **Screen Recording** (System Settings → Privacy & Security → Screen Recording), then reopen KhmerClip.

1. បើក `KhmerClip-0.1.0.dmg` ហើយអូស **KhmerClip** ទៅដាក់ក្នុង **Applications**។
2. បើក KhmerClip ពី Applications។ រូបតំណាងរបស់វានឹងបង្ហាញនៅលើរបារម៉ឺនុយ ខាងលើអេក្រង់។
3. ពេលវាសួរ សូមអនុញ្ញាត **Screen Recording** (System Settings → Privacy & Security → Screen Recording) រួចបើក KhmerClip ម្តងទៀត។

### Windows

1. Double-click `KhmerClip-0.1.0-windows-x64-setup.exe`.
2. If you see **"Windows protected your PC"**, click **More info**, then **Run anyway**. This appears because the app isn't signed with a paid Microsoft certificate yet. It is safe to install.
3. Follow the steps to finish installing. KhmerClip starts in the system tray (bottom-right corner of the screen).

1. ចុចពីរដងលើ `KhmerClip-0.1.0-windows-x64-setup.exe`។
2. ប្រសិនបើឃើញ **"Windows protected your PC"** សូមចុច **More info** រួចចុច **Run anyway**។ សារនេះលេចឡើង ព្រោះកម្មវិធីមិនទាន់មានវិញ្ញាបនបត្រ (certificate) ពី Microsoft នៅឡើយ។ កម្មវិធីនេះមានសុវត្ថិភាពក្នុងការដំឡើង។
3. ធ្វើតាមជំហាន ដើម្បីបញ្ចប់ការដំឡើង។ KhmerClip នឹងដំណើរការនៅក្នុង system tray (ជ្រុងខាងស្តាំផ្នែកខាងក្រោមនៃអេក្រង់)។

### Linux

1. Make the file executable: right-click → Properties → Permissions → **Allow executing file as program**, or run `chmod +x KhmerClip-0.1.0-x86_64.AppImage`.
2. Double-click it to start. On GNOME, the tray icon needs the **AppIndicator** extension (already on in Ubuntu).

1. អនុញ្ញាតឱ្យឯកសារដំណើរការបាន៖ ចុចកណ្តុរស្តាំ → Properties → Permissions → **Allow executing file as program** ឬវាយ `chmod +x KhmerClip-0.1.0-x86_64.AppImage`។
2. ចុចពីរដងលើវា ដើម្បីចាប់ផ្តើម។ នៅលើ GNOME រូបតំណាងក្នុង tray ត្រូវការ extension **AppIndicator** (Ubuntu មានរួចហើយ)។

## Use · របៀបប្រើ

1. Press **⌘⇧6** (Mac) or **Ctrl+Shift+2** (Windows / Linux), or choose **Capture Text** from the KhmerClip icon.
2. Drag a box around the text. The text is copied. Paste it anywhere.

1. ចុច **⌘⇧6** (Mac) ឬ **Ctrl+Shift+2** (Windows / Linux) ឬជ្រើស **Capture Text** ពីរូបតំណាង KhmerClip។
2. អូសប្រអប់ជុំវិញអក្សរ។ អក្សរនឹងត្រូវបានចម្លង។ យកទៅបិទភ្ជាប់ (paste) កន្លែងណាក៏បាន។

**Better Khmer accuracy · ភាពត្រឹមត្រូវខ្ពស់ជាងសម្រាប់អក្សរខ្មែរ:** in **Preferences → OCR Engine**, choose **TrOCR**. On Windows and Linux it downloads once (about 1.5 GB) the first time you use it.

នៅក្នុង **Preferences → OCR Engine** សូមជ្រើស **TrOCR**។ នៅលើ Windows និង Linux វានឹងទាញយកម្តង (ប្រហែល 1.5 GB) នៅពេលប្រើលើកដំបូង។

**Wayland (Linux):** add a keyboard shortcut in your desktop settings that runs `/path/to/KhmerClip-0.1.0-x86_64.AppImage --capture`.

---

Everything runs on your computer. Your screen captures are never uploaded. · ដំណើរការទាំងអស់កើតឡើងនៅលើកុំព្យូទ័ររបស់អ្នក។ រូបភាពអេក្រង់របស់អ្នកមិនត្រូវបានផ្ញើទៅកន្លែងណាទេ។
