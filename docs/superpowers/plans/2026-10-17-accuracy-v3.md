# Accuracy v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measure accuracy on realistic screen captures, then try every suggested improvement (wide-line splitting, Unicode normalization, confidence-gated beam, content-crop parity, a v3 fine-tune with screen-style synth + KhmerST + LazyGreed) and keep only what measurably helps.

**Architecture:** A new auto-labelled `fixtures_screen/` set (Chrome-rendered multi-line Khmer clips in held-out macOS/Khmer OS fonts) plus a Python end-to-end pipeline runner (`trocr-pipeline`: Mac-identical line split + 384² resize + greedy decode with repeat cap) are the gate. Each candidate is a flag on the pipeline runner; winners get ported to Swift (`TrOCREngine`) and desktop (`preprocess.py`/`trocr.py`) and confirmed on-device with `OCRBench`.

**Tech Stack:** Python 3.12, PyTorch/transformers (MPS locally, CUDA on the 3090 via `scripts/remote.sh`), headless Google Chrome, Swift/CoreML, onnxruntime.

**Spec:** the user's request (2026-10-17) plus the six suggestions in that conversation. No separate spec file.

## Global Constraints

- Frozen 200-fixture set (`training/eval/fixtures/`) is never modified.
- macOS fonts (Khmer Sangam MN, Khmer MN) and Khmer OS fonts are **eval-only**; training fonts stay OFL (README promise; Apple/Khmer OS licenses).
- Screen-set text must not come from training label pools; dedup checked.
- Training: start from v2 (`experiments/checkpoint-5/final`), lr 1e-5, 1 epoch, same flags as `run_v2.sh` unless a task says otherwise.
- App-side changes must keep Mac and desktop behaviour identical (desktop is a port of Swift).

## Gate (keep/drop rule, applied to every candidate)

Paired per-fixture comparison against the current baseline, reported as: total char errors, fixtures improved / worsened, CER per subset.

- **Keep** if: screen-set char errors drop ≥ 5% with improved > worsened, AND frozen-200 char errors rise by ≤ 3, AND English UI line accuracy (`eval_english.py`) does not drop, AND median latency stays ≤ 2× Tesseract (existing gate).
- **Drop** otherwise; record numbers and reason in `training/eval/results/accuracy_v3.md`.

## Review Focus

- Long line with no inter-word gaps (Khmer rarely uses spaces): splitter must fall back to a cluster-safe cut or no cut, never cut through a glyph → test `test_split_wide_no_gap`.
- Wide splits joined wrongly (space inserted where label has none, or dropped where it has one) → join rule test `test_join_rule`.
- Dark-mode clip (light text on dark) through splitter → `test_split_wide_dark`.
- Multi-line clip vs `recognize_many` (one stdout line per image): OCRBench already space-joins; labels must be space-joined → loader test.
- Retina (2×) clips with very tall strips: splitter uses strip height, not absolute px → covered by 2× fixtures in screen set.

### Task 1: Screen fixture set (`fixtures_screen/`)

**Files:**
- Create: `training/eval/scripts/build_screen_fixtures.py`
- Create: `training/eval/tests/test_screen_fixtures.py`

- Output stays local (`.gitignore`): Wikipedia text (CC BY-SA) rendered in non-redistributable system fonts.

**Design:**
- Text: Khmer Wikipedia (`wikimedia/wikipedia`, `20231101.km`), cut at spaces into lines of 20–120 chars; ~10% lines get an English phrase spliced in (mixed). ZWSP removed from labels (invisible).
- Dedup: run on the 3090 box; drop any line sharing a 16-char shingle with labels of the training sources. Report overlap rate.
- Render: one HTML page per fixture, each line its own `<div style="white-space:nowrap">`, headless Chrome `--screenshot --force-device-scale-factor={1,2}`, fonts `Khmer Sangam MN`, `Khmer MN`, `Khmer OS System`, `Khmer OS Battambang`, `Khmer OS`, 12–20 css px, line-height 1.4–1.8, light/dark. Clip cropped to text bbox + random padding.
- Subsets: `screen` = 1–5 lines per clip (300 clips); `screen_long` = single line 60–120 chars (150 clips). Label = lines joined by single space.
- Seeded and deterministic.

### Task 3: Inference candidates (each gated independently)

**Files:** `training/eval/src/khmerclip_eval/pipeline.py`, `training/eval/tests/test_pipeline.py`

- (a) **Wide split**: if strip aspect `w/h > R` (R tuned), cut at a blank column gap nearest each ideal cut point; wide gap → join with " ", narrow → "". No blank column near the ideal point → keep strip whole. Tests: `test_split_wide_gap`, `test_split_wide_no_gap`, `test_split_wide_dark`, `test_join_rule`.
- (b) **Normalize**: post-decode Khmer cleanup. First measure how references are encoded; only apply rules references follow. Test `test_normalize_idempotent_on_refs` (every fixture ref unchanged).
- (c) **Beam gate**: re-decode with beam 4 when min token prob of greedy line < T. Latency counted.
- (d) **Crop**: desktop's `content_crop` on vs off.
